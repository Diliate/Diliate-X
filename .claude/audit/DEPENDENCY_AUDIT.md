# DEPENDENCY_AUDIT.md — DILIATE X

## Diliate (main site) dependencies

| Package                                 | Decision                              | Reason                                                                                                                                                             |
| --------------------------------------- | ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `react`, `react-dom` 18                 | **KEEP (version validated)**          | Current major version, fine to carry the version baseline forward under Next.js.                                                                                   |
| `firebase`                              | **DELETE**                            | No auth/login system in V2 scope (`ENGINEERING_AUDIT.md`). Removes an entire class of security/maintenance surface area for a marketing site that doesn't need it. |
| `react-router` / `react-router-dom`     | **DELETE**                            | Replaced by Next.js App Router file-based routing — redundant once on Next.js.                                                                                     |
| `@headlessui/react`, `@heroicons/react` | **REPLACE**                           | V2 standardizes on shadcn/ui + Lucide (`TechStack.md`) for a single consistent primitive/icon system.                                                              |
| `react-bootstrap`                       | **DELETE**                            | Bootstrap-based components conflict with the Tailwind/shadcn token system — real architectural debt if carried forward.                                            |
| `react-calendly`                        | **ARCHIVE (not installed at launch)** | No booking flow in V2 launch scope; reintroduce only if a "book a call" CTA is added later.                                                                        |
| `react-ga`, `react-gtm-module`          | **REPLACE**                           | Migrate intent to native GA4 (`@next/third-parties` or direct gtag script) — current packages target older GA/GTM integration patterns.                            |
| `react-helmet`                          | **DELETE**                            | Next.js's built-in `generateMetadata` replaces this entirely — redundant and actually conflicts with SSR metadata best practices.                                  |
| `react-icons`                           | **REPLACE**                           | Consolidate to Lucide only (per `Design.md`/`ComponentLibrary.md`) — avoids the mixed-icon-family debt flagged in `ASSET_INVENTORY.md`.                            |
| `react-preloaders`, `react-spinners`    | **DELETE**                            | No full-page preloader pattern in V2 (`ENGINEERING_AUDIT.md`).                                                                                                     |
| `@mdbootstrap/react-testimonial-slider` | **DELETE**                            | Testimonials deferred (`ComponentLibrary.md`); when built, use a custom component matching the design system, not a Bootstrap-derived slider.                      |
| `framer-motion`                         | **KEEP**                              | Already specced as V2's component-level animation library (`TechStack.md`).                                                                                        |
| `sass`                                  | **DELETE**                            | Tailwind covers styling needs; no `.scss` architecture needed in V2.                                                                                               |
