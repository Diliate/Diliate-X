## Data Fetching Convention

Standard REST semantics — GET for reads (Server Components fetching directly, or route handlers if an external client needs the data), Server Actions for writes/mutations (contact form). No custom HTTP verbs — these aren't supported by browsers, CDNs, or Vercel's edge network, so all data interactions use the standard HTTP method set.
